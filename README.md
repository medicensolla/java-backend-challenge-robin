# Java Backend Challenge

REST API for a sports training facility: coach assignment, session scheduling, and participant registration.

## Project status

Planning workspace created. Application implementation starts with the tickets in [the project plan](docs/JBC-project-plan.md).

## Planned stack

Java 21, Spring Boot 3, Maven Wrapper, PostgreSQL, Flyway, JUnit, Testcontainers, and Docker Compose.

## Development conventions

- Ticket IDs: `JBC-001`, `JBC-002`, and so on.
- Branch names must exactly match the ticket ID.
- Conventional Commits include the ticket ID: `feat(sessions): JBC-007 add session creation`.
- One pull request per ticket; include the ticket ID in its title and description.
- Preserve released Flyway migrations unchanged.

See the project plan for requirements, acceptance criteria, dependencies, optional enhancements, and submission checks.
